# 🎰 彩票智能选号系统 V3.0

Hermes 技能 **lottery-analysis-smart-v2** —— 中国彩票（福彩3D / 排列三 / 大乐透）数据分析 + 智能选号。

## ⚠️ 数学声明（必读）

**彩票开奖是独立随机事件。** 每期开奖号码与历史数据无关，任何分析都不能提高命中率（推荐命中率≈1%，与随机选号相同）。

本项目的价值在于**选号质量**而非预测：让号码组合符合概率分布（和值7-20占83.2%、跨度4-7占56.4%、组六占72%、奇偶/大小1:2或2:1各占37.5%），避免极端组合。**不构成任何投注建议。**

## 功能

- **官方API数据获取**：cwl.gov.cn（福彩3D）、sporttery.cn（排列三/大乐透）
- **统计分析**：频率、和值、跨度、奇偶、大小、012路、形态（组六/组三/豹子）、遗漏、信息熵
- **智能选号 V3.0**：贝叶斯后验 + 指数衰减热度 + 复隔中分析，12维评分 + 8种候选策略共识
- **大乐透专业分析**：15维评分系统，前区/后区独立建模

## 使用方法

```bash
cd scripts
python run_analysis.py --games 3d,35 --count 100
```

| 彩种代码 | 彩种 | 数据源 |
|:---:|:---|:---|
| `3d` | 福彩3D | cwl.gov.cn |
| `35` | 排列三 | sporttery.cn |
| `85` | 大乐透 | sporttery.cn |

多个彩种用逗号分隔：`--games 3d,35,85`

## 评分系统 V3.0 核心维度（12维）

贝叶斯后验(15) · 指数衰减热度(12) · 和值合理性(12) · 跨度合理性(10) · 形态加分(10) · 奇偶平衡(8) · 大小平衡(8) · 012路多样(6) · 复隔中加分(6) · 遗漏甜蜜区(5) · 质合平衡(4) · 伴随号加分(4)

候选策略（8种）：贝叶斯采样 / 指数衰减热号 / 复隔中组合 / 和值目标采样 / 跨度目标采样 / 遗漏回补组合 / 伴随号组合 / 蒙特卡洛过滤
